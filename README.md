# 定时关机助手 · Shutdown Timer

![banner](docs/banner.png)

定时关机助手（Shutdown Timer）是一款免费开源的 Windows 定时关机软件：深色现代界面、环形进度倒计时、执行前弹窗提醒、8 种界面语言，专为「睡前挂机」场景设计。

**[⬇️ 下载最新版 exe（免安装，双击即用）](https://github.com/3042407270bj-dot/shutdown-timer/releases/latest)** · 无需 Python，个别杀毒软件误报请添加信任

## ✨ 功能

- ⏱ **倒计时 / 定点** 两种定时模式，支持 **关机 / 重启 / 休眠** 三种任务
- 🕐 空闲时环中央显示当前时间；设定任务后变为渐变进度环实时倒计时
- 🔔 执行前 1 分钟右下角弹窗提醒，可直接 **取消任务 / 推迟 10 分钟 / 忽略**
- ⚡ 快捷时间：15 / 30 / 60 / 120 分钟一键填入，定点 +1 / +2 小时自动换算
- 🌍 **8 种界面语言**：简体中文 / English / Français / Русский / Español / العربية / 繁體中文 / Latina，顶栏地球图标一键循环切换
- 🌙☀️ 深 / 浅主题切换，窗口置顶
- 💾 自动记住上次设置（模式、时间、主题等）
- 🎨 高 DPI 适配 + PIL 超采样抗锯齿渲染，高分屏下依然细腻
- 🖼 应用图标内嵌于脚本，单文件复制到其他电脑图标依然有效

## 🚀 使用

```bash
# 方式一：直接双击 定时关机.pyw（需已安装 Python）
# 方式二：
python 定时关机.pyw
```

1. 选择「倒计时」或「定点」模式，填入时间
2. 选择任务类型（关机 / 重启 / 休眠）
3. 点击「开始任务」，进度环开始倒计时
4. 随时可点「取消任务」撤销

| 项目 | 说明 |

## 💡 设计说明

- **关机与重启由系统 `shutdown` 命令计时**——设定后即使关闭本程序，任务依然有效
- 「休眠」因系统命令不支持延时，由本程序计时执行，请保持程序运行（退出时会提醒）
- 图标为「电源环 + 时钟指针」融合设计，与应用内 logo 呼应
